# Frontend Transformation: Strategic Action Plan

**Owner:** Carsten dittmann **Status:** ongoing.

* * *

## 1\. Executive Summary

We're running a dual-track transformation across our GUIs:

**Track A — AI-Native Development:** Transition frontend developers from traditional coding workflows to AI-prompt-driven development (Cursor, Claude, Copilot, etc.), starting with the snc/opcp team and aligning them with the mainstream manager team who are further ahead. It is critical that we get on boarded within a timely manner to not cause delays in Q3.

**Track B — UX Unification:** Enforce consistent adoption of our shared design system across all three product lines & mainstream managers (snc, opcp, mainstream manager), turning a poorly-adopted system into the single source of truth. This means we have to to join a bi-directional feedback loop, one where we get feedback from mainstream how "starting a vm" or "help" UX should be. But where we can also give feedback to the main UX stream for topics that don't fit OPCP (airgap/navigation) etc.

**Why these tracks reinforce each other:** AI coding tools are only as good as the patterns they're prompted with. A well-documented, consistently adopted design system _becomes the prompt library_ — it gives AI tools clear constraints and reusable patterns. Doing both at once is a multiplier, not extra work.

**Affected people:** 3 frontend developers (Sylviu, Tobi, Maxime, Jan) + 1 UX designer (Leena).

**General goal:** Yaniv gave us the go for max "2 week" delay, to learn the new approach.
