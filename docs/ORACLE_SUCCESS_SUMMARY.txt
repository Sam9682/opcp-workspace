🎯 FONCTIONNALITÉS PRINCIPALES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 💬 INTERFACE DE CHAT
   • Conversation en temps réel avec l'IA
   • Sélection du fournisseur d'IA
   • Historique des conversations
   • Suggestions de questions

2. 📊 WIDGET D'ANALYSE
   • Analyse automatique du forum
   • Prédictions de perte d'emplois (5, 10, 20 ans)
   • Identification des sujets clés
   • Analyse de sentiment

3. 🔌 API REST
   • POST /api/oracle/ask - Poser une question
   • GET /api/oracle/history - Historique
   • POST /api/oracle/analyze/forum - Analyser le forum
   • GET /api/oracle/providers - Liste des fournisseurs

4. 🤖 FOURNISSEURS D'IA
   • Kiro AI (local, par défaut)
   • Shai AI (OVH Cloud)
   • OpenAI (GPT-4)

5. 🔒 SÉCURITÉ
   • Authentification JWT
   • Rate limiting (10/min, 5/h)
   • Validation des entrées
   • Gestion sécurisée des clés API

📝 PROCHAINES ÉTAPES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ⚙️  CONFIGURATION (5 minutes)
   cp .env.example .env
   nano .env  # Ajouter vos clés API

2. 🗄️  MIGRATION DE LA BASE DE DONNÉES
   alembic upgrade head

3. 🔧 INSTALLATION DE KIRO-CLI (optionnel)
   bash scripts/install_kiro_cli.sh

4. 🚀 DÉMARRER L'APPLICATION
   uvicorn app.main:app --reload
   cd frontend && npm run dev

5. ✅ TESTER
   http://localhost:5173 → Se connecter → 🔮 L'Oracle (AI)
